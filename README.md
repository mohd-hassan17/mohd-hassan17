## 🎨 Featured Projects

### [AskCortex](https://github.com/mohd-hassan17/AskCortex)
> AI-powered chat platform supporting 30+ LLMs with RAG pipelines and streaming responses

**Tech Stack:** Next.js, React.js, TypeScript, PostgreSQL, TanStack Query, Shadcn UI, Vercel AI SDK, OpenRouter

**Key Features:**
- Model switching across 30+ LLMs with web search and context-aware responses
- RAG pipelines for low-latency, multi-model querying
- Persistent chat history with authentication and responsive UI

### [Converso](https://github.com/mohd-hassan17/converso)
> Real-time AI voice assistant with multi-turn conversational memory

**Tech Stack:** Next.js, React.js, Supabase, TypeScript, OpenAI API, Clerk

**Key Features:**
- Speech-to-text, LLM processing, and text-to-speech pipeline
- Low-latency streaming with context-aware memory
- Secure authentication and persistent conversation history

**Tech Stack:** Next.js, React.js, PostgreSQL, Judge0, TypeScript, Shadcn UI

**Key Features:**
- Real-time code execution and multi-test case validation via Judge0 APIs
- Scalable REST APIs for submission, execution, and evaluation
- Secure sandboxing with optimized request handling
